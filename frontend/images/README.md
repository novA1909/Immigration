# Images Directory

## Add Your Logo Here

To complete the website setup, please add your logo to this directory:

1. **Save your logo file as:** `eventzz-planet-logo.png`
2. **Place it in this directory:** `frontend/images/`

### Your logo should be:
- PNG format with transparent background
- Approximately 400-600px wide
- High quality for crisp display

### The logo will appear:
- In the navigation bar at the top
- In the footer at the bottom

For detailed instructions, see: [LOGO_INSTRUCTIONS.md](../LOGO_INSTRUCTIONS.md)

---

## Additional Images

You can also add images for the gallery section:
- Save gallery images in this directory
- Use descriptive names (e.g., `wedding-decor-1.jpg`, `corporate-event-1.jpg`)
- Recommended size: 800x600px or larger
- Supported formats: JPG, PNG, WebP

Then update the gallery section in `index.html` to display your images.
